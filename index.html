    Sticks, gyro and accelerometer are decoded on every report but deliberately not used to keep the radio awake — worn sticks jitter and a controller on a table is never perfectly still. One exception: a shake over 2.25 g cancels the sleep timer, the same rule AntennaPod uses for shake-to-reset.

    The trigger actuator — not the grip motors — buzzes while that trigger is changing the volume. Lower force and rate make it subtler; the test buttons apply the current settings immediately.

    power_save_control (+0x09, gated by valid_flag1 bit 1). Bit 4 is documented as microphone mute, bit 6 as audio mute; the rest are guesses — if one stops the motion sensors, the gyro/accelerometer above will go flat.

    A map of field name to byte value (or array of bytes), framed and CRC-signed for you. Field names and offsets live in lib/padwave/schemas/ (also at /api/schema) — try { "valid_flag2": 2, "lightbar_setup": 1 } or { "valid_flag1": ["lightbar"], "lightbar_red": 255, "led_brightness": 60 }.
